# Firmware

Welcome to the core of the TNY-360!

The firmware is the software running inside the robot. It connects the electronics, movement system, sensors, user interface, and remote control features together.

You do not need to understand the firmware to use your TNY-360. However, learning how it works will help you understand its behavior, troubleshoot issues, and create more advanced programs.
