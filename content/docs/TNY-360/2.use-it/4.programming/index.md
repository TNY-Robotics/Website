# Programming

Let's go deeper and learn how to program your TNY-360 using Python, Javascript, or other programming languages!

This section is designed for developers and robotics enthusiasts who want to create more complex behaviors and functionalities for their TNY-360 quadruped robot.

---



## Available SDKs

To program your TNY-360, you'll need the appropriate *Software Development Kits (SDKs)*. These SDKs provide the necessary tools and libraries to interact with your robot and control its movements, sensors, and other features.

Here are the available SDKs for programming your TNY-360:

:section-button{href="./javascript" title="Javascript/TypeScript SDK" desc="The Javascript/TypeScript SDK allows you to control your TNY-360 from any JavaScript environment, including Node.js and web browsers."}

## API Reference

All the SDKs (Python, Javascript/TypeScript, C/C++, ...) are built **on top of the same underlying API** that uses Websockets to communicate with the robot.

This makes all SDKs structured in a similar way. So we built a dedicated [API Reference](./api-ref) section where you can find all the details about the available methods and types, you can use in every SDK.

:section-button{href="./api-ref" icon="lucide:book" title="API Reference" desc="The API Reference provides a detailed overview of the available methods and types for controlling your TNY-360, regardless of the SDK you are using."}
