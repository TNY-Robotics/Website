# Block Coding

Your TNY-360 can be quickly programmed to perform custom behaviors using its block-based programming interface.

Here's how to use it and create your first custom behavior for your TNY-360!

---

## Open the block coding interface

Connect to your TNY-360's web interface, then click the **Program my TNY-360** button to open the block coding interface.

If you do not know how to connect to the web interface, follow the [Getting Started](../get-started) guide first.

## Create a program

The block coding interface is designed to be used on a computer. It is divided into two main areas:

- the block library on the left;
- the programming workspace on the right.

Your program is organized around two events:

- **Setup:** runs once when the program starts;
- **Loop:** runs repeatedly for as long as the program is running.

Drag blocks from the library into the appropriate event and connect them in the workspace to create your robot's behavior.

::info-box{title="Not sure where to start?" type="tip"}
Open the **Examples** menu in the top-left corner to browse ready-made programs and use them as a starting point.
::

## Run your program

The controls in the bottom-right corner of the interface allow you to manage your program on the robot:

- **Run:** start the program;
- **Stop:** stop the program;
- **Pause:** temporarily pause the program;
- **Resume:** continue a paused program;
- **Step:** execute the program step by step.

Use the step-by-step mode to observe how your blocks are executed and better understand what your program is doing.

You are now ready to create your first custom behavior for your TNY-360!
