# The Extension Board

Here's the first PCB you'll need to solder for your TNY-360: the Extension Board.

This one is pretty easy, with big solder pads and a few components only, but make sure to double check the orientation of the connectors :)

::info-box{title="How to use" type="tip"}
If this is your first time seeing the window below, you might be wondering how to use it.

This is pretty simple: <br> You will find a list of all the components needed for this PCB, as well as a visual representation of the board next to it.
Simply click on one of the components in the list, and it will highlight its position on the board, so you can easily find where to solder which component.
::
